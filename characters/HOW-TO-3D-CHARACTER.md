# 캐릭터 일러스트 → 웹 3D 말랑이 만들기 가이드

뽀모 고양이를 만든 과정을 다른 캐릭터에도 그대로 쓸 수 있게 정리한 문서입니다.
결과물은 **브라우저에서 돌려볼 수 있는 HTML 파일 하나**와 **4뷰 이미지(정면/측면/후면/윗면)**,
그리고 나중에 **블렌더 메타볼**로 옮길 수 있는 **구 좌표표**입니다.

> 참고 구현: `characters/ppomo-cat/ppomo-cat-3d.html`
> 새 캐릭터는 이 파일을 복사해서 **형태표(SHAPE)·색(PAL)·형태 계산(modelSDF)** 세 군데만 바꾸면 됩니다.

---

## 0. 큰 그림: 왜 "구"로 만드나

- 캐릭터를 **구(타원체 포함) 여러 개의 집합**으로 쪼갭니다. 머리, 몸통, 볼, 귀, 다리, 배, 엉덩이 = 각각 구 하나 또는 몇 개.
- 이 구들을 **메타볼처럼 부드럽게 녹여** 한 덩어리로 보이게 합니다. 이음새가 자연스럽게 사라집니다.
- 같은 좌표·반지름을 블렌더 메타볼에 그대로 넣으면 같은 형태가 나옵니다. 웹 = 설계도, 블렌더 = 최종 모델.
- 부위마다 크기 값을 따로 두면 **볼만, 배만, 엉덩이만** 따로 키울 수 있습니다(뽀모의 빵빵폼).

## 1. 준비물

| 항목 | 내용 |
|---|---|
| 캐릭터 일러스트 | 정면 1장은 필수. 3/4 각도나 옆모습이 있으면 훨씬 정확해짐 |
| (선택) 레퍼런스 사진 | 원하는 질감·자세 예시 (예: 말랑한 실리콘 스퀴시 장난감) |

| 브라우저 | 크롬 권장. 결과 HTML을 더블클릭해서 열면 됨 |
| (선택) 블렌더 | 메타볼로 최종 모델을 만들 때 |

인터넷 연결이 필요합니다. HTML이 3D 엔진(Three.js)을 CDN에서 불러옵니다.

## 2. 작업 순서 (뽀모에서 실제로 효과 있었던 순서)

### 2-1. 일러스트를 "부위 목록"으로 쪼개기

일러스트를 보고 부위를 구 단위로 나눕니다. 먼저 글로 정리하면 AI에게 설명하기 쉽습니다.

```
- 머리: 큰 구 1개 (살짝 가로로 넓게)
- 몸통: 앞뒤로 긴 타원체 1개 + 엉덩이 쪽 구 1개 (등이 뒤로 갈수록 높게)
- 볼: 얼굴 양옆에 구 2개 (크게, 앞으로 튀어나오게)
- 귀: 머리 위 구 2개
- 앞발/뒷발: 바닥 쪽 작은 구 4개
- 배: 몸통 아래쪽 납작한 타원체 1개
- 엉덩이: 뒤쪽 구 2개
- 눈/입: 표면에 붙는 작은 장식 (녹이지 않음)
```

**팁**
- 처음부터 디테일(뾰족 귀, 발가락, 털 무늬)을 넣지 마세요. 구로 단순하게 → 나중에 블렌더에서 다듬기.
- "따로 커져야 하는 부위"(뽀모의 볼/배/엉덩이)는 처음부터 **독립 부위**라고 명시하세요.

### 2-2. 2D 원 구성도로 비율 먼저 잡기 (선택이지만 추천)

바로 3D로 가면 비율 수정이 번거롭습니다. 먼저 **원으로 된 구성도(정면/측면/후면/윗면)** 를 SVG로 그려
비율을 확인하고 넘어가면 시행착오가 줄어듭니다.

- 좌표계: 몸 중심 기준, y = 위, z = 앞(얼굴 쪽), 단위는 "몸 반지름 = 1" 같은 상대값
- 각 원에 번호(C1, C2…)를 붙여 두면 "C5를 좀 위로" 처럼 수정 요청하기 쉬움

### 2-3. 3D 웹 뷰어 만들기

AI에게 아래 3장의 "프롬프트 템플릿"을 주고, 일러스트를 첨부합니다.
뽀모 HTML이 있다면 같이 첨부하고 **"이 파일 구조를 그대로 쓰고 형태표만 바꿔줘"** 라고 하는 게 가장 빠릅니다.

### 2-4. 4뷰로 확인하고 수정 반복

- 뷰어 주소 뒤에 `?sheet` 를 붙이면 4뷰가 한 화면에 나옵니다. (예: `ppomo-cat-3d.html?sheet`)
- 수정은 **한 번에 2~3개씩**, 구체적으로 요청하세요.
  - 좋은 예: "앞다리를 구로 바꾸고 볼과 안 붙게 옆으로 빼줘. 몸 길이 10%만 줄여줘."
  - 나쁜 예: "좀 더 귀엽게"
- 레퍼런스 이미지를 같이 주면 형태가 확 좋아집니다(뽀모도 레퍼런스 5장을 준 뒤에 "엎드린 식빵 자세"로 잡힘).

### 2-5. 색 입히기

- 부위별 파스텔 색이 **몸통 색으로 부드럽게 번지게** 하려면, 색을 "위치에 따른 함수"로 칠하세요(아래 4-3).
- 부위 메쉬마다 단색을 칠하면 경계가 딱 끊겨 보입니다.

### 2-6. 블렌더로 넘기기 (선택)

- 형태표(JSON)의 좌표·반지름으로 메타볼 요소를 배치합니다(5장).

## 3. 프롬프트 템플릿 (복사해서 쓰기)

```
첨부한 캐릭터 일러스트를 Three.js로 웹에서 돌려볼 수 있는 3D 캐릭터로 만들어줘.

[결과물]
- HTML 파일 1개. 빌드 없이 브라우저에서 바로 열림.
- Three.js 0.160.0을 importmap으로 jsdelivr CDN에서 불러오기 (버전 고정).
- OrbitControls로 드래그 회전/휠 줌, 자동 회전 토글 버튼.
- 주소 뒤에 ?sheet 를 붙이면 정면/측면/후면/윗면 4뷰를 한 화면에 직교 카메라로 렌더.

[형태 원칙]
- 캐릭터 전체를 구(타원체 포함)의 집합으로만 만든다. 나중에 블렌더 메타볼로 옮길 예정.
- 모든 구를 SDF smooth union(smin)으로 녹여 하나의 표면으로 만든다. 부위마다 녹는 정도(k)를 따로 둔다.
- 표면은 격자 기반(surface nets 또는 marching cubes)으로 추출하고, 법선은 SDF 기울기로 계산.
- 바닥은 평평하게 (y=0 근처에서 smooth max로 잘라냄).
- 눈/입 같은 작은 장식은 녹이지 말고 표면 위에 붙이는 별도 메쉬로.
- 모든 구의 위치/반지름은 코드 맨 위 SHAPE 표 하나에 모아줘.

[독립 부위]
- (예: 볼 좌/우, 배, 엉덩이)는 각자 크기 값을 갖고, window.캐릭터.setScale('부위', 배율)로
  따로 키울 수 있게. 키운 뒤 표면을 다시 계산해서 이음새가 부드럽게 유지되게.
- 크기가 바뀌면 눈/입 위치도 표면에 다시 붙게.

[재질/색]
- MeshPhysicalMaterial, 무광 실리콘 느낌 (roughness 0.6, clearcoat 0.2, sheen 약간).
- 색은 vertex color로: 몸통 기본색 + 부위별 파스텔 색이 그 부위에서 몸통 쪽으로 부드럽게 번지게.
  (색 = 위치의 함수 → 경계가 끊기지 않음)
- 조명: HemisphereLight + DirectionalLight(그림자) + RoomEnvironment. 밝고 부드러운 스튜디오 톤.
- 배경: 밝은 단색 그라데이션.

[색 지정]
- 몸통: #______  /  (부위1): #______  /  (부위2): #______

[부위 설명]
(2-1에서 정리한 부위 목록 붙여넣기)

먼저 4뷰 시트를 렌더해서 보여주고, 내가 수정 요청하면 SHAPE 숫자만 바꿔서 반영해줘.
```

## 4. 기술 메모 (AI가 헷갈릴 때 짚어줄 것)

### 4-1. 형태 = SDF smooth union

```js
// 두 거리값을 부드럽게 합치기. k가 클수록 많이 녹음
const smin = (a, b, k) => { const h = Math.max(k - Math.abs(a - b), 0) / k;
                           return Math.min(a, b) - h * h * k * 0.25; };
const sph = (x,y,z, cx,cy,cz, r) => Math.hypot(x-cx, y-cy, z-cz) - r;

function modelSDF(x, y, z) {
  let d = sph(x,y,z, 0,0.6,0.68, 0.62);                 // 머리
  d = smin(d, sph(x,y,z, -0.39,0.45,1.05, 0.31*scaleL), 0.10);  // 볼 L (독립 배율)
  // ... 나머지 부위
  return smax(d, -(y - 0.035), 0.12);                   // 평평한 바닥
}
```

뽀모에서 쓴 녹는 정도(k): 머리-몸통 0.2, 몸통-엉덩이볼륨 0.35, 볼 0.10, 배·엉덩이 0.12, 다리 0.08, 귀 0.07.
**작게 = 형태가 또렷, 크게 = 더 뭉개짐.** 귀·다리는 작게, 큰 덩어리끼리는 크게.

### 4-2. 표면 뽑기

- 구 하나하나를 메쉬로 꽂으면 이음새가 보임 → 반드시 **격자에서 표면 추출** (surface nets가 코드 짧고 결과 부드러움).
- 격자 간격 0.02 정도면 충분히 매끈함. 크기 바꿀 때마다 다시 계산 (뽀모 기준 약 1초).
- **계산 범위(BOUNDS)가 형태보다 작으면 윗부분이 잘려 보입니다.** 부위를 최대 배율로 키웠을 때까지 들어가게 넉넉히.

### 4-3. 색 번짐

- 각 부위 중심 바깥쪽 표면에 "색 발생점"을 두고, 거리에 따라 몸통 색 → 부위 색으로 섞습니다.
- 색 계산을 메쉬별로 하지 말고 **위치 함수 하나**로 하면 어느 메쉬든 같은 위치는 같은 색 → 경계 없음.

### 4-4. 4뷰 시트

- 직교 카메라 1개로 화면을 4칸 나눠(viewport/scissor) 정면/측면/후면/윗면을 렌더.
- 윗면에서는 바닥 그림자를 끄세요(그림자가 덩어리처럼 보임).

## 5. 블렌더 메타볼로 옮기기

1. 형태표(JSON)의 각 구 = 메타볼 요소 1개. 타원체는 요소 타입을 Ellipsoid로 하고 size_x/y/z 설정.
2. **같은 계열 이름**(예: `Cat`, `Cat.cheekL`, `Cat.belly`)이면 오브젝트가 달라도 서로 녹아붙습니다.
   → 볼/배/엉덩이를 별도 오브젝트로 두고 따로 스케일해도 매끄럽게 연결됨.
3. 메타볼 반지름은 웹 반지름과 1:1로 같지 않습니다(붙는 부위끼리 서로 부풀림). Stiffness와 반지름은 블렌더에서 눈으로 맞추기.
4. 평평한 바닥은 메타볼로 안 됨 → Object > Convert > Mesh 후 Boolean이나 Bisect로 바닥 자르기.
5. 웹의 그라데이션 색은 안 넘어갑니다 → 버텍스 페인트 또는 머티리얼에서 다시.
6. AI에게 "형태표 JSON을 읽어서 메타볼을 배치하는 Blender Python 스크립트 만들어줘"라고 하면 자동 배치 가능.

## 6. 실제로 겪은 문제와 해결 (체크리스트)

| 증상 | 원인 | 해결 |
|---|---|---|
| 색이 거의 흰색으로 날아감 | 조명/노출이 너무 셈 | toneMappingExposure, 조명 세기 낮추기 |
| 파스텔이 탁하고 칙칙함 | 조명이 너무 어둡고 회색빛 | 노출 1.0 근처, Hemisphere 하늘색 흰색, 해 살짝 따뜻하게 |
| 부위 경계가 딱 끊겨 보임 | 메쉬마다 단색 | 4-3 위치 기반 색 번짐 |
| 구를 꽂은 티가 남 | 메쉬를 따로따로 꽂음 | 4-1, 4-2 SDF + 표면 추출 |
| 등/머리가 잘려 보임 | 계산 범위가 작음 | BOUNDS 넓히기 |
| 볼을 키우면 눈이 묻힘 | 눈 위치 고정 | 크기 바뀔 때 눈/입을 표면에 다시 붙이기 |
| 갑자기 몸통이 투명/안 보임 | 코드 수정 중 처음 표면 계산 줄이 지워짐 | 페이지 로드 시 rebuild()가 꼭 실행되는지 확인 |
| 몸이 소시지처럼 길쭉함 | 몸통 앞뒤 반지름 과다 | 몸통 z 반지름 10%씩 줄이며 확인 |
| 다리가 볼에 붙음 | 볼이 바닥까지 늘어짐 | 다리를 옆/뒤로 빼서 간격 0.03~0.05 확보 |

## 7. 공유할 때

- **노션 임베드:** HTML 파일을 노션에 업로드해 임베드할 수 있지만, 노션이 외부 스크립트(CDN)를 막으면 빈 화면이 뜰 수 있습니다. 4뷰 PNG는 항상 같이 넣으세요.
- **링크 공유:** Claude 아티팩트 링크는 기본 비공개입니다. 다른 사람에게 보여주려면 Share 메뉴에서 공개 설정.
- **다른 호스팅:** GitHub Pages, Netlify 등에 HTML 하나만 올리면 누구나 열 수 있는 주소가 생깁니다.
