# 뽀모 테스트 벤치 (오늘 가진 부품만으로)

## 준비물
- Arduino Nano 33 IoT, 브레드보드, 점퍼선
- 플렉스 센서 2개 (숍 대여), 10kΩ 저항 2개 (센서의 펴진 상태 저항과 비슷한 값이면 더 좋음: 10k~47k)
- LED 1개 + 220Ω (진동 모터 대신 "셌다" 표시)
- 테스트 몸: 갖고 있는 스트레스볼 / 인형 / 폼 조각

## 배선
```
3.3V ── 플렉스 센서(배) ──┬── A0          3.3V ── 플렉스 센서(엉덩이) ──┬── A1
                         └── 10kΩ ── GND                               └── 10kΩ ── GND
D2 ── 220Ω ── LED(+)   LED(−) ── GND
```
센서 하나만 쓸 때는 펌웨어의 `USE_BUTT_SENSOR`를 `false`로.

## 순서
1. Arduino IDE로 `../ppomo-firmware/nano33-flex-test/nano33-flex-test.ino` 업로드 (보드: Arduino NANO 33 IoT)
2. 시리얼 모니터는 닫고, **데스크톱 크롬/엣지**에서 `index.html`을 연다 (파일 더블클릭)
3. **기기 연결 (USB)** → 포트 선택. 연결 직후 1초는 손대지 않기(기준값 측정)
4. 쥐어보면서 그래프를 보고, 누름/놓임 판정 슬라이더로 맞추기 (바로 기기에 반영됨)
5. 테스트 절차표를 하나씩: 시작 → 동작 → 끝. **결과 복사**로 기록

기기 없이 화면만 보려면 **데모 모드** (B 키 = 배, N 키 = 엉덩이).

## 플렉스 센서 붙이는 법 (테스트용)
- 플렉스 센서는 **휘어짐**을 잡습니다. 쥘 때 실제로 휘는 면에 붙여야 반응합니다.
- 1차: 스트레스볼 **겉면**에 테이프로 붙이고 쥐어보기 (가장 빠름)
- 2차: 칼집을 내서 **안쪽 면**에 붙이기 → 실제 뽀모 구조와 비슷
- 센서 다리(납작한 끝)는 꺾이면 잘 망가지니, 다리 쪽은 테이프로 단단히 고정하고 휘는 부분은 몸통 쪽에 두기
