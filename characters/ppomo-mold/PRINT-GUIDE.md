## 캐스팅 순서
1. 몰드 안쪽, 코어, 다리 전부에 Ease Release 200.
2. 코어 두 쪽을 필라멘트 핀으로 맞추고 붙이기 → 이음선 사포질.
3. 코어를 왼쪽 몰드에 놓기 (손잡이가 앞 구멍으로, 날개가 앞면에 닿게).
4. 오른쪽 몰드를 맞물리고 볼트 4개 조이기.
5. 뒤집어서 바닥(붓는 쪽)이 위로. 다리를 얹고 기둥을 코어 구멍에, 핀 2개를 몰드 구멍에 꽂기.
6. 실리콘 약 200 g 섞기 → 탈포 → 다리 옆 열린 곳으로 가늘게 붓기 → 윗면까지.
7. 4시간 뒤: 볼트 풀기 → 몰드 열기 → **다리+기둥을 먼저 배 쪽으로 빼기** → 코어를 얼굴 구멍으로 당겨 빼기.
