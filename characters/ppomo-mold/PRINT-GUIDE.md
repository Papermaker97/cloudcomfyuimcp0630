## 버전 2: 속 빈 몸 (`mold-v2-hollow/`)
| 파일 | 개수 | 출력 방향 |
|---|---|---|
| mold-v2-left.stl | 1 | 그대로 (바깥 면이 바닥, 공간이 위) |
| mold-v2-right.stl | 1 | 그대로 |
| core-top.stl | 1 | 그대로 (평평한 자른 면이 바닥) |
| core-bottom.stl | 1 | 그대로 (평평한 자른 면이 바닥) |
| bridge-post.stl | 1 | 그대로 (다리가 바닥, 기둥이 위) |
- 실리콘 1회 약 194 g. M4 볼트 16–20 mm + 너트 4개. 1.75 mm 필라멘트 조각 2개(코어 핀).
- 코어 두 쪽: 핀 구멍에 필라멘트를 꽂아 맞추고 접착 → 이음선 사포질.

## 공통 설정
- PLA 또는 PETG, 노즐 0.4, 레이어 0.2 mm (코어와 몰드 안쪽은 0.12–0.16 mm면 더 매끈)
- 벽 3–4줄, 채움 15–20%, 서포트 없음
- 실리콘이 닿는 면: 사포 → XTC-3D 코팅(선택) → Ease Release 200

## 버전 2 캐스팅 순서
1. 몰드 안쪽, 코어, 다리 전부에 Ease Release 200.
2. 코어를 왼쪽 몰드에 놓기 (손잡이가 앞 구멍으로, 날개가 앞면에 닿게).
3. 오른쪽 몰드를 맞물리고 볼트 4개 조이기.
4. 뒤집어서 바닥(붓는 쪽)이 위로. 다리를 얹고 기둥을 코어 구멍에, 핀 2개를 몰드 구멍에 꽂기.
5. 실리콘 약 200 g 섞기 → 탈포 → 다리 옆 열린 곳으로 가늘게 붓기 → 윗면까지.
6. 4시간 뒤: 볼트 풀기 → 몰드 열기 → **다리+기둥을 먼저 배 쪽으로 빼기** → 코어를 얼굴 구멍으로 당겨 빼기.
