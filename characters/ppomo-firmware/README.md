# Ppomo 펌웨어 (XIAO ESP32-C3 + FSR 402 ×2 + 코인 진동 모터)

| 파일 | 내용 |
|---|---|
| `main.cpp` | 고친 버전. 이걸 Schematik(또는 Arduino/PlatformIO)에 넣어서 빌드 |
| `main.schematik-original.cpp` | Schematik이 만든 원본 (비교용) |
| `test/run.sh` | PC에서 감지 로직만 시뮬레이션 (원본 vs 고친 버전) |

핀, 타이밍(40 ms 확인 / 120 ms 릴리즈 / 75 ms 진동), 메시지 형식은 원본과 같습니다.

## 고친 점
1. **천천히 쥐면 안 세지던 문제** — 기준값이 쥐는 도중의 상승을 따라 올라가던 것을, 손이 완전히 떨어진 상태(+120 이내)에서만 아주 천천히(약 20초) 따라가게 변경.
2. **한 번 세고 나서 영영 안 세지던 문제** — 폼이 눌린 채 남거나 오래 쥐고 있으면 다시 셀 수 없게 갇히던 것을, 4초가 지나면 현재 값을 새 기준으로 삼아 재무장(꾹 쥐고 있어도 1회만 셈).
3. 기준값을 소수(float)로 계산해 정수 반올림 쏠림 제거.
4. `millis()` 넘김(약 49일)에도 진동이 꺼지도록 경과시간 방식으로 비교.

## 실제 센서로 맞출 값
- `PRESS_DELTA` (기본 260), `RELEASE_DELTA` (기본 120): 폼 속에 넣은 뒤 시리얼로 값을 보면서 조정.
- 전원 켜고 처음 1초는 손대지 않기 (기준값 측정).
- 시리얼이 안 나오면 빌드 설정에서 **USB CDC On Boot = Enabled** 확인.
