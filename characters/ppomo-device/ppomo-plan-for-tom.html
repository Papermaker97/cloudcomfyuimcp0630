Ppomo: what I plan to build first

Ppomo is a squeezable companion. One squeeze is one event: the device counts squeezes and does not interpret them. At the Winter Show, an on-screen Ppomo sits on a visitor's head or shoulder and grows each time the physical Ppomo is squeezed.

Inside Ppomo

The board keeps the count itself (one squeeze = one event, using a threshold with a gap between press and release) and sends squeeze,<count> over USB serial. When the screen app connects, it asks for the current count, so squeezes made while it was closed are not lost. Interactive concept model: Ppomo Prototype v1.

Why the FSR wins for the Winter Show

  • It already worked in my labs. Fewer new variables before December.
  • Cheap and simple to replace if it breaks.
  • Counting squeezes doesn't need precise force.
  • Only the sensor changes if I upgrade later. The counting code and the screen stay the same.

The air-bulb option I'm keeping for v2

  • A single-opening rubber bulb (the ear-irrigation kind, about $1.40–$5.40) in the butt, a silicone tube (about $0.77–$1.70/ft) to a pressure sensor in the head.
  • Sensor candidates: CFSensor XGZP6847A, analog (a 3.3 V, 0–5 kPa version lists at $7.80; the range I'd need is unpriced) or Adafruit MPRLS, I2C, $29.95.
  • Not a blood-pressure bulb: its one-way valves keep pumping the pressure up.
  • I'll switch if user tests show the FSR missing squeezes.

Body: silicone cast in a printed mold

For a squeeze toy, cast silicone should feel softer and survive longer than a rubber-like print. Smooth-On lists Ecoflex 00-30 at Shore 00-30 with 900% elongation. I already have the 95 mm sitting Ppomo model, so I can print the mold directly.

  1. 1
    Print a two-part mold (front/back) from the model, with alignment keys and a pour hole. FDM PLA.
  2. 2
    Add removable cores: a head cavity for the electronics, a butt cavity for the sensor stack, and a channel between them.
  3. 3
    Cast: mold release, mix, degas, pour, cure (about 4 hours for Ecoflex 00-30).
  4. 4
    Insert parts after curing through the base opening.
Watch-outs. Platinum silicone won't cure against latex or sulfur (Smooth-On's FAQ). I'll use nitrile gloves, an FDM mold rather than resin, and a small test cast first. Mold layer lines transfer to the surface, so the mold needs smoothing. Ecoflex 00-30 is very soft and may feel tacky, so I want to compare two hardnesses on small samples. Trial unit: $32.99 from Smooth-On.

Test plan, in order

The counts here (20, 500, 5 people) are the tests I plan to run, not results.

  1. 1
    Bench: 20 deliberate squeezes give a count of 20.
    If not → tune the threshold, or change how the FSR is mounted.
  2. 2
    Small silicone samples: cure test and feel of two hardnesses.
    If it won't cure → change the mold material or the silicone.
  3. 3
    FSR + puck inside a cast body: squeezed vs. resting is still clear through the silicone.
    If not → bigger puck or a sensor closer to the surface, then the air bulb.
  4. 4
    500 squeezes: values stay separable, nothing tears, the wire survives the service loop.
    If not → change the mounting or the wire.
  5. 5
    Unplug and replug: the count comes back. Then screen sync after reconnecting.
    If not → change where the count is stored, or the sync.
  6. 6
    5+ people, unprompted: do they squeeze where the sensor is?
    If not → reshape the butt or guide the squeeze.
