2003년 한국 완구 CF. 필름 질감, 하이키 조명, 렌즈 플레어, 쨍한 원색.
총 15초.

이야기: 밤새 작업하던 여자가 손바닥만한 투명 기기 '케이샘플러'의 RUN 버튼을
누르자 마법소녀로 변신한다.

비트 (시간 배분 대략):
- 3초  방. CRT 앞에 앉아 렌더 끝나기를 기다리는 지친 얼굴.
- 2초  손 안의 케이샘플러. 엄지가 RUN 버튼 위로 올라간다.
- 2초  누른다. 기기가 부품으로 분해되어 떠올랐다가 빛과 함께 다시 합쳐진다.
- 5초  변신. 방이 빛에 씻겨 날아가고 마법소녀가 된다.  ← 제일 긴 비트
- 3초  결정 포즈를 잡고 홀드하다가 로고 카드로 끝.

레퍼런스 역할 (연결 순서 = 번호):
- 이미지1 = 케이샘플러의 전체 형태, 투명 플라스틱 재질, 버튼과 포트 배치.
           배경과 조명은 가져오지 말 것.
- 이미지2 = 기기가 분해된 상태의 내부 부품 구성만. 배경·조명은 가져오지 말 것.
- 이미지3 = 버튼 누르는 매크로 인서트의 화각과 손가락 디테일.
- 이미지4 = 여자의 얼굴, 그리고 오프닝 장소.
           이 방과 CRT 모니터, 책상 위 잡동사니를 그대로 가져올 것.
- 이미지5 = 변신 후의 의상, 헤어스타일, 포즈만.
           배경은 절대 가져오지 말 것. 합성 배경이며 실제 장소가 아니다.
- 이미지6 = 엔딩 로고 카드. 마지막 프레임으로 그대로 사용.

동일 인물 고정: 이미지4의 여자와 이미지5의 마법소녀는 같은 사람이다.
얼굴 생김새는 이미지4를 따른다. 변신하면서 안경을 벗고 머리가 트윈테일로
바뀔 뿐, 얼굴은 처음부터 끝까지 동일하다. 두 이미지를 섞어 제3의 얼굴을
만들지 말 것.

소리: Y2K 신스 징글. 마우스 클릭, 버튼 딸깍, 부품이 맞물리는 소리,
변신할 때 차임과 휘몰아치는 바람.
변신 직전 여자가 외친다 (한국어): "케이샘플러, 런!"
엔딩 나레이터 (한국어): "케이샘플러."

이미지6의 로고 외에는 화면에 글자나 자막이 나오지 않게 할 것.
