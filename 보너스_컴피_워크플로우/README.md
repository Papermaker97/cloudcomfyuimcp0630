## 01. 한 장으로 여러 각도 생성 (Nano Banana Pro)

**파일 없음 — comfy.org 공식 템플릿을 그대로 씁니다.** 용량이 커서(약 190KB) 직접
받아오지 못했습니다. 아래 방법으로 직접 받으세요 (제 환경은 막혀있지만 강사님
컴퓨터/브라우저는 문제없습니다):

- 브라우저에서 열기: **https://cloud.comfy.org/templates/templates-multiple_consistent_shots-nb_pro.json**
  (열리면 Ctrl+S로 저장)
- 또는 Comfy Cloud 접속 → 템플릿 검색창에 **"Single Image to Multiple Consistent Shots"** 검색 → 바로 불러오기

**사용법**: `Load Reference Image` 노드에 상품 사진 1장 로드 → 실행하면
Gemini가 자동으로 카메라 앵글 6개(정면/측면/45도/클로즈업 등) 프롬프트를 스스로
만들어서, Nano Banana Pro로 각 앵글의 이미지를 한 번에 6장 생성합니다.
**모델**: Nano Banana Pro (`gemini-3-pro-image-preview`)

## 02. 배경 교체 + 재조명 — Nano Banana Pro 버전

파일: `02_배경교체_재조명_나노바나나프로.json`

**노드 구조**: LoadImage(상품 원본) + LoadImage(배경 레퍼런스) → BatchImagesNode →
GeminiImage2Node(Nano Banana Pro) → SaveImage

**임포트 방법**: ComfyUI/Comfy Cloud 화면에 이 json 파일을 그대로 드래그 앤 드롭

**실행 전 설정 2곳**:
1. 첫 번째 `LoadImage` 노드 → 상품 원본 사진 업로드 (예: `01_INPUT/beauty_01.png`)
2. 두 번째 `LoadImage` 노드 → 원하는 배경 분위기의 레퍼런스 이미지 업로드
   (없으면 상품 사진을 그대로 다시 넣어도 됨 — 프롬프트 글로만 배경을 설명하는 방식)

**프롬프트(이미 입력해뒀음, 필요시 라이브로 수정)**:
> "이 상품 사진(image0)의 상품 자체는 모양·색상·로고·질감을 절대 바꾸지 말고,
> 배경만 image1을 참고하여 자연스럽게 교체해줘. 새 배경의 조명 방향과 색온도에
> 맞춰 상품에 드리운 그림자와 하이라이트도 함께 자연스럽게 다시 그려줘."

## 03. 배경 교체 + 재조명 — GPT 이미지2 버전

파일: `03_배경교체_재조명_GPT이미지2.json`

**노드 구조**: LoadImage(상품 원본) → OpenAIGPTImageNodeV2(GPT Image 2) → SaveImage
(02번보다 단순한 구조 — 배경 레퍼런스 이미지 없이 프롬프트 글로만 배경 지정)

**실행 전 설정**: `LoadImage` 노드에 상품 원본 사진 업로드

**프롬프트(이미 입력해뒀음)**:
> "이 상품 사진에서 상품 자체(모양·색상·로고·질감)는 절대 바꾸지 말고, 배경만
> 밝고 깨끗한 스튜디오 화이트 배경 또는 따뜻한 톤의 라이프스타일 배경으로
> 자연스럽게 교체해줘. 새 배경의 조명 방향에 맞춰 상품에 드리운 그림자와
> 반사광도 사실적으로 다시 그려줘."
