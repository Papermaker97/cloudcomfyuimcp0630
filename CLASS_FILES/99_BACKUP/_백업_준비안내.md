# 99_BACKUP — 라이브 실패 대비 완성본 (강사용)

실습이 밀리거나 대여 노트북이 안 따라올 때 **즉시 배포**할 완성본을 여기에 둡니다.
(교안 §5.9 보험 자료)

## 넣어둘 것
- [ ] `상품배너_액션.atn` — Photoshop 액션 완성본 (규격 변환/저장 액션)
- [ ] `완성배너_예시.jpg` — 배너채우기 결과 완성본 JPG 1~2장
- [ ] `broadcast_template_완성.aep` — 표현식·EGP까지 다 적용된 AE 완성본
- [ ] `방송영상_예시.mp4` — 렌더까지 끝낸 출력 영상 1개

## 쓰는 순간
- 스크립트가 특정 노트북에서 안 돌 때 → 완성 JPG/MP4를 바로 배포해 결과부터 보여줌.
- 실습 시간이 부족할 때 → "결과물은 이렇게 나옵니다"로 마무리하고 파일 배포.
- 빔프로젝터 무선 연결이 영상 미리보기에서 끊길 때 → 사전 렌더된 mp4로 시연.

## 만드는 법 (요약)
1. 02/03 폴더의 템플릿이 완성되면, 표준 config.json으로 각 스크립트를 1회 실행.
2. 05_OUTPUT에 생성된 결과물 중 대표 1~2개를 이 폴더로 복사.
3. AE는 OUTPUT 렌더큐를 실제 렌더해 mp4 확보.
