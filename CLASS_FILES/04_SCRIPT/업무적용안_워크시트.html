오늘 배운 핵심: "코드는 만지지 않는다. 데이터만 바꾼다." 엔진(액션·템플릿·검증된 스크립트)은 그대로 두고, 데이터(이미지·상품명·가격·규격)만 교체합니다. 아래 5단계로 내 반복 업무 1개를 자동화 설계해 봅니다.

STEP 1. 내 반복 업무 고르기 — 매주/매 방송마다 되풀이하는 손이 많이 가는 일

자동화할 반복 업무예) 방송별 상품 배너 20종을 규격별로 다시 저장
얼마나 자주 하나요?예) 방송 준비마다 / 주 3회
1회당 평균 소요 시간예) 약 90분

STEP 2. 업무를 3조각으로 쪼개기 (INPUT → PROCESS → OUTPUT)

INPUT (입력)
가진 것: 원본 이미지, 상품명·가격, 로고 …
▶
PROCESS (반복 작업)
되풀이하는 손작업: 리사이즈, 누끼, 문구 교체 …
▶
OUTPUT (결과물)
최종 산출: 규격별 배너 JPG, 방송 영상 …
작성 예시 — INPUT: 상품 원본 사진 1장 + 상품명/가격  ▶  PROCESS: 정사각·가로·세로 3규격 리사이즈, 배경 흰색 채움  ▶  OUTPUT: 규격별 JPG 3장

STEP 3. 어떤 단계가 자동화 가능한가?

사람이 판단할 부분
(감각·선택·검수)		예) 어떤 컷이 상품이 예쁘게 나왔는지 고르기
기계가 반복할 부분
(자동화 대상)		예) 규격 변환, 파일명 규칙 저장, 텍스트 교체
