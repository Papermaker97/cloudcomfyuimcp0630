============================================================
 표현식(Expression) 예시 모음 — After Effects
------------------------------------------------------------
 이 파일은 "코드를 외우는 것"이 목적이 아닙니다.
 아래 두 표현식을 복사해서 붙여넣고, 값(숫자·이름)만 바꾸는
 연습을 하기 위한 예시집입니다.  — "코드는 만지지 않는다. 데이터만 바꾼다."

 표현식 붙여넣는 법:
   1) 속성(예: 소스 텍스트, 크기)의 스톱워치를 Alt(⌥)+클릭
   2) 나타난 입력칸에 아래 코드를 붙여넣기
   3) 입력칸 바깥을 클릭하면 적용

 이 파일에서 실제로 복사할 코드는 아래처럼
   ┌── 여기부터 복사 ── / └── 여기까지 복사 ──
 로 감싸진 박스 안쪽 줄들뿐입니다. 박스 밖의 설명 글은 복사하지 마세요.
============================================================


────────────────────────────────────────────────────────────
 [예시 1] 배경 박스 자동 리사이즈  (상품명 길이에 맞춰 박스가 늘고 줄어듦)
────────────────────────────────────────────────────────────

 ★ 아주 중요 — 어디에 붙이나:
   셰이프 레이어(사각형) 그 자체가 아니라,
   레이어 안쪽의  콘텐츠 > 사각형 1 > 사각형 경로 1 > "크기(Size)"
   속성에 붙여야 합니다. (엉뚱한 곳에 붙이면 undefined 오류가 납니다)

 ★ 두 가지 버전이 있습니다 — 상황에 맞는 걸 쓰세요:
   · 기본형: 텍스트 레이어 "1개"만 박스가 감쌀 때 (예: 상품명만)
   · 확장형: 텍스트 레이어 "2개"를 박스 하나가 같이 감쌀 때
            (이 실습 템플릿처럼 하단바 안에 상품명+가격이 나란히 있는 경우 — 이걸 쓰세요)

────────────────────────────────────────────────────────────
 기본형 — 텍스트 1개만 감쌀 때
────────────────────────────────────────────────────────────

 (A) "크기(Size)" 에 붙일 표현식
 아래 ┌ ─ ┐ 박스 안의 4줄만 마우스로 긁어서 복사하세요. (박스 밖 글자는 복사하지 마세요)

 ┌── 여기부터 복사 ──────────────────────────────────────────
 │ // 글자를 읽어올 텍스트 레이어의 이름입니다. (레이어 이름과 정확히 같아야 함)
 │ txt = thisComp.layer("PRODUCT_NAME");
 │ // 박스가 글자보다 얼마나 더 클지 좌우/상하 여백(px)입니다. 이 숫자만 바꾸면 됩니다.
 │ pad = [40, 24];
 │ // 지금 시각(time)에 텍스트가 차지하는 실제 영역을 잽니다. (width/height/left/top)
 │ s = txt.sourceRectAtTime(time, false);
 │ // 글자 크기에 여백을 양쪽(×2)으로 더한 값을 박스 크기로 돌려줍니다.
 │ [s.width, s.height] + pad*2;
 └── 여기까지 복사 ──────────────────────────────────────────


 (B) 같은 사각형 경로의 "위치(Position)" 에 붙일 짝꿍 표현식
 (박스를 글자 중앙에 딱 맞추기 위한 것입니다. 위 (A)와 세트로 씁니다)

 ┌── 여기부터 복사 ──────────────────────────────────────────
 │ // 위와 같은 텍스트 레이어를 읽어옵니다.
 │ txt = thisComp.layer("PRODUCT_NAME");
 │ // 텍스트가 차지하는 영역을 다시 잽니다.
 │ s = txt.sourceRectAtTime(time, false);
 │ // 그 영역의 정중앙 좌표를 계산해 박스의 중심으로 삼습니다.
 │ [s.left + s.width/2, s.top + s.height/2];
 └── 여기까지 복사 ──────────────────────────────────────────

 ※ (B)가 잘 맞으려면: 박스(셰이프) 레이어의 "위치"와 "앵커 포인트"를
    글자 텍스트 레이어와 같은 기준으로 맞춰두세요.
    (실습 템플릿에는 이미 맞춰져 있습니다. 값만 바꿔 쓰면 됩니다)


────────────────────────────────────────────────────────────
 확장형 — 상품명 + 가격, 텍스트 2개를 하나의 하단바가 같이 감쌀 때
────────────────────────────────────────────────────────────

 ※ 기본형 그대로 쓰면 박스가 PRODUCT_NAME 하나만 재기 때문에,
   PRICE 글자가 박스 밖으로 튀어나옵니다. 이 버전으로 교체하세요.

 (A) "크기(Size)" 에 붙일 표현식

 ┌── 여기부터 복사 ──────────────────────────────────────────
 │ // 상품명과 가격, 두 텍스트 레이어를 모두 읽어옵니다.
 │ nameLayer = thisComp.layer("PRODUCT_NAME");
 │ priceLayer = thisComp.layer("PRICE");
 │ // 박스가 글자보다 얼마나 더 클지 여백(px)입니다.
 │ pad = [40, 24];
 │ // 각 텍스트가 실제로 차지하는 영역(자기 자신 기준 좌표)을 잽니다.
 │ nameRect = nameLayer.sourceRectAtTime(time, false);
 │ priceRect = priceLayer.sourceRectAtTime(time, false);
 │ // 각 텍스트의 위치를 더해서, 화면(컴포지션) 기준 좌표로 바꿉니다.
 │ nameLeft = nameLayer.transform.position[0] + nameRect.left;
 │ nameRight = nameLeft + nameRect.width;
 │ nameTop = nameLayer.transform.position[1] + nameRect.top;
 │ nameBottom = nameTop + nameRect.height;
 │ priceLeft = priceLayer.transform.position[0] + priceRect.left;
 │ priceRight = priceLeft + priceRect.width;
 │ priceTop = priceLayer.transform.position[1] + priceRect.top;
 │ priceBottom = priceTop + priceRect.height;
 │ // 두 텍스트를 모두 감싸는 가장 바깥 범위를 계산합니다.
 │ left = Math.min(nameLeft, priceLeft);
 │ right = Math.max(nameRight, priceRight);
 │ top = Math.min(nameTop, priceTop);
 │ bottom = Math.max(nameBottom, priceBottom);
 │ // 그 범위에 여백을 더해 박스 크기로 돌려줍니다.
 │ [(right - left), (bottom - top)] + pad*2;
 └── 여기까지 복사 ──────────────────────────────────────────

 (B) 같은 사각형 경로의 "위치(Position)" 에 붙일 짝꿍 표현식

 ┌── 여기부터 복사 ──────────────────────────────────────────
 │ nameLayer = thisComp.layer("PRODUCT_NAME");
 │ priceLayer = thisComp.layer("PRICE");
 │ nameRect = nameLayer.sourceRectAtTime(time, false);
 │ priceRect = priceLayer.sourceRectAtTime(time, false);
 │ nameLeft = nameLayer.transform.position[0] + nameRect.left;
 │ nameRight = nameLeft + nameRect.width;
 │ nameTop = nameLayer.transform.position[1] + nameRect.top;
 │ nameBottom = nameTop + nameRect.height;
 │ priceLeft = priceLayer.transform.position[0] + priceRect.left;
 │ priceRight = priceLeft + priceRect.width;
 │ priceTop = priceLayer.transform.position[1] + priceRect.top;
 │ priceBottom = priceTop + priceRect.height;
 │ left = Math.min(nameLeft, priceLeft);
 │ right = Math.max(nameRight, priceRight);
 │ top = Math.min(nameTop, priceTop);
 │ bottom = Math.max(nameBottom, priceBottom);
 │ [(left + right)/2, (top + bottom)/2];
 └── 여기까지 복사 ──────────────────────────────────────────

 ※ 주의: 이 확장형을 쓰려면 PRODUCT_NAME·PRICE 두 레이어가
   MAIN 컴포지션에 "그대로(Pre-compose 하지 않고)" 있어야 합니다.
   Pre-compose로 두 레이어를 합쳐버리면 영상채우기.jsx 스크립트가
   PRODUCT_NAME/PRICE 레이어를 못 찾아 에러가 납니다.


────────────────────────────────────────────────────────────
 [예시 2] 가격 카운트업  (0원에서 목표 가격까지 1초 동안 숫자가 올라감)
────────────────────────────────────────────────────────────

 ★ 어디에 붙이나:
   가격을 보여줄 텍스트 레이어의  "소스 텍스트(Source Text)" 에 붙입니다.
 ★ 준비물 (★★★ 순서 중요 — 꼭 PRICE 레이어 자신에게 넣을 것):
   1) 반드시 "PRICE 레이어 자체"를 선택한 상태에서
      Effect > Expression Controls > "슬라이더 제어(Slider Control)" 를 추가하세요.
      (다른 레이어에 넣으면 "effect가 없다"는 오류가 납니다.
       표현식은 "지금 이 레이어 안에서" 이펙트를 찾기 때문입니다)
   2) 그 이펙트 이름을 정확히  "가격"  으로 바꿔두세요.
      (표현식의 "가격"과 이펙트 이름이 글자 하나까지 같아야 합니다)
   3) 슬라이더 값에 목표 가격(예: 25000)을 넣습니다.

 "소스 텍스트" 에 붙일 표현식
 아래 ┌ ─ ┐ 박스 안의 3줄만 마우스로 긁어서 복사하세요. (박스 밖 글자는 복사하지 마세요)

 ┌── 여기부터 복사 ──────────────────────────────────────────
 │ // "가격"이라는 이름의 슬라이더 이펙트에서 목표 숫자를 읽어옵니다. (1 = 슬라이더 값 자리, 언어 상관없이 항상 동작)
 │ target = effect("가격")(1);
 │ // 레이어 시작(inPoint)부터 1초 동안 0 → 목표값까지 부드럽게 올라가는 숫자를 만듭니다.
 │ n = Math.round(linear(time, inPoint, inPoint + 1, 0, target));
 │ // 그 숫자에 천 단위 콤마(1,234)를 붙이고 뒤에 "원"을 붙여 화면에 보여줍니다.
 │ n.toString().replace(/\B(?=(\d{3})+(?!\d))/g, ",") + "원"
 └── 여기까지 복사 ──────────────────────────────────────────

 ※ 왜 toLocaleString을 안 쓰나:
    toLocaleString은 프로그램 버전에 따라 콤마가 안 나올 때가 있어,
    어느 버전에서나 똑같이 동작하는 위 방식(정규식 콤마)을 씁니다.

 ※ 왜 ("슬라이더") 대신 (1) 을 쓰나:
    After Effects가 영문판이면 파라미터 이름이 "슬라이더"가 아니라 "Slider"라서
    이름으로 부르면 또 오류가 납니다. (1)은 "그 이펙트의 첫 번째 값"이라는 뜻이라
    한글판/영문판 상관없이 항상 동작합니다.


────────────────────────────────────────────────────────────
 자주 나는 오류와 해결 (강사용 방어 노트)
────────────────────────────────────────────────────────────

 · "undefined value used in the expression" (크기 표현식):
     → 셰이프 레이어가 아니라 "사각형 경로 > 크기"에 붙였는지 확인.

 · "effect named '가격' is missing or does not exist":
     → 슬라이더 이펙트를 PRICE가 아닌 다른 레이어(로고 등)에 넣은 경우 발생.
       PRICE 레이어 자체에 슬라이더 이펙트가 있는지 확인.

 · 가격이 안 바뀌거나 오류:
     → 슬라이더 이펙트 이름이 정확히 "가격"인지 확인. (공백/오타 주의)

 · "layer ... 를 찾을 수 없음":
     → thisComp.layer("이름")의 이름이 실제 레이어 이름과 같은지 확인.

 · 이 표현식들이 이해가 안 될 때:
     → PART 5에서 배운 대로, 코드를 통째로 AI에게 붙여넣고
       "이 표현식을 한 줄씩 한국어로 설명해줘" 라고 물어보세요.
