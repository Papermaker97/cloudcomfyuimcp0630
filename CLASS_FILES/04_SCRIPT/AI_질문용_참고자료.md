# 신세계라이브쇼핑 AI 자동화 수업 — AI 질문용 참고자료

> **사용법**: 실습 중 막히면, 이 문서 전체를 복사해서 ChatGPT/Claude 대화창에
> 먼저 붙여넣고, 그 아래에 질문이나 에러 메시지를 이어서 적으세요.
> 이 문서가 없으면 AI가 우리 수업과 상관없는 일반적인 답변(또는 틀린 답변)을
> 줄 수 있습니다. 이 문서를 주면 우리 수업 기준으로 정확하게 답해줍니다.

## 이 문서를 읽는 AI에게 (먼저 읽어주세요)

당신은 지금 **"AI를 활용한 Adobe 그래픽 업무 자동화"** 오프라인 강의를 듣는
수강생을 돕고 있습니다. 아래 규칙을 지켜서 답변해 주세요.

1. **수강생은 비개발자**이며, 오늘 코드를 새로 작성하지 않습니다. "스크립트를 새로
   짜드릴게요"보다는, **아래 정해진 템플릿·파일·이름 안에서 원인을 찾아** 설명해 주세요.
2. 이 문서에 적힌 **파일명·레이어명·구조가 정답**입니다. 이 문서에 없는 내용을
   추측해서 지어내지 마세요.
3. 오늘 수업의 핵심 원칙: **"코드는 만지지 않는다. 데이터만 바꾼다."**
   (엔진 = 액션/템플릿/스크립트, 데이터 = 이미지·상품명·가격)
4. 답변은 **비전문가가 이해할 수 있는 쉬운 말**로, 문법 용어보다 "무엇을 클릭/수정
   하면 되는지" 위주로 설명해 주세요.

## 1. 오늘 쓰는 폴더 구조

```
CLASS_FILES/
├── 01_INPUT/           상품 이미지 원본 (product_01.png ~ product_05.png)
├── 02_PHOTOSHOP/       banner_template.psd
├── 03_AFTER_EFFECTS/   broadcast_template.aep
├── 04_SCRIPT/          자동화 스크립트 + config.json + 이 문서
└── 05_OUTPUT/          결과물이 저장되는 폴더 (실습 전엔 비어있음)
```
바탕화면에 압축 해제해서 씁니다. 폴더/파일 이름은 바꾸면 안 됩니다.

---

## 2. 오늘 쓰는 템플릿의 정확한 이름 (★ 제일 중요)

이름이 하나라도 다르면 자동화가 작동하지 않습니다. 오타·공백·한글 변경 주의.

### Photoshop — `banner_template.psd`의 레이어
| 레이어 이름 | 종류 | 역할 |
|---|---|---|
| `PRODUCT_IMAGE` | 스마트 오브젝트 | 상품 사진 (더블클릭하면 내용 교체 가능) |
| `PRODUCT_NAME` | 텍스트 | 상품명 |
| `PRICE` | 텍스트 | 가격 |
| `LOGO` | 일반 | 더미 브랜드 로고 (고정) |
| `BACKGROUND` | 일반 | 배경 (고정) |

### After Effects — `broadcast_template.aep`
- 프로젝트 항목: `LOGO`(푸티지), `MAIN`(컴포지션), `OUTPUT`(컴포지션), `PRODUCT_IMAGE`(푸티지)
- `MAIN` 컴포지션 안의 레이어: `LOGO`, `PRICE`(텍스트), `PRODUCT_NAME`(텍스트), 하단바(셰이프 레이어), `PRODUCT_IMAGE`, `BACKGROUND`
- `OUTPUT` 컴포지션 = `MAIN`을 안에 담고 있는 최종 출력용 컨테이너 (렌더는 항상 OUTPUT을 내보냄)
- **필수 그래픽(Essential Graphics) 패널에 등록된 4개**:
  1. **상품명** — PRODUCT_NAME의 텍스트 내용
  2. **가격** — 슬라이더 숫자 (0~9,999,999원 범위, 숫자만 입력)
  3. **브랜드 컬러** — 하단바 색상
  4. **상품 이미지** — 이미지 교체 슬롯 (드래그해서 바꾸기)

## 3. 자동화 스크립트 3종 (강사 시연용 — 수강생은 직접 실행하지 않음)

| 스크립트 | 하는 일 | 실행 경로 |
|---|---|---|
| `규격변환.jsx` | 01_INPUT 상품 이미지 전체를 1080×1080 / 1920×1080 / 1080×1920 규격 JPG로 일괄 변환 | Photoshop: 파일 > 스크립트 > 찾아보기 |
| `배너채우기.jsx` | `config.json` 값을 읽어 banner_template.psd의 이미지·상품명·가격을 자동으로 채우고 JPG 저장 | Photoshop: 파일 > 스크립트 > 찾아보기 |
| `영상채우기.jsx` | `config.json` 값을 읽어 broadcast_template.aep의 이미지·텍스트를 채우고 렌더큐에 등록 | After Effects: 파일 > 스크립트 > 스크립트 파일 실행 |

세 스크립트 모두 **코드를 안 고치고, `config.json`이라는 데이터 파일만 읽어서** 작동합니다.

---

## 4. config.json 문법 규칙 (오류의 90%가 여기서 남)

```json
{
  "productName": "신상 초코 케이크",
  "price": 25000,
  "productImage": "01_INPUT/product_01.png",
  "brandColor": "#E8452C",
  "outputSizes": ["1080x1080", "1920x1080"]
}
```

**딱 4규칙**:
1. 값과 값 사이에는 **쉼표(,)**
2. **맨 마지막 값 뒤에는 쉼표 없음**
3. 글자 값은 **큰따옴표("")**로 감싸기 (숫자인 price는 따옴표 없음)
4. 파일 경로도 따옴표 안에, `01_INPUT/파일명` 형태 (루트 폴더 기준 상대경로)

## 5. 자주 발생하는 문제 TOP 5 (정확한 원인)

| 증상 | 실제 원인 | 해결 |
|---|---|---|
| "OO 레이어를 찾을 수 없습니다" | PSD/AEP의 레이어 이름이 위 §2 표와 다르게 바뀜 | 레이어 이름을 정확히 되돌리기 (영문 대문자+언더스코어) |
| "config.json 문법에 오류가 있습니다" | 쉼표 누락/과다, 따옴표 누락 | §4의 4규칙 순서대로 확인 |
| "상품 이미지를 찾을 수 없습니다" | config.json의 productImage 경로와 실제 01_INPUT 파일명이 다름 (오타 포함) | 파일명을 정확히 일치시키기 |
| AE에서 스크립트 실행이 막힘 | 환경설정에서 "스크립트가 파일에 쓰고 네트워크에 액세스하도록 허용"이 꺼져 있음 | 편집(After Effects) > 환경 설정 > 스크립팅 및 표현식에서 체크 |
| 검은 화면으로 렌더됨 | OUTPUT 컴포지션 안에 MAIN이 레이어로 들어있지 않음 (빈 채로 렌더됨) | OUTPUT을 열어 MAIN이 레이어로 들어있는지 확인 |

## 6. 오늘 배우는 핵심 개념 (AI가 답할 때 이 용어를 써주세요)

- **INPUT → PROCESS → OUTPUT**: 자동화를 "무엇이 들어와서 → 어떻게 처리되어 → 무엇이 나오는지"로 쪼개는 사고방식
- **엔진(고정) vs 데이터(가변)**: 엔진 = 액션·템플릿·스크립트(안 바뀜), 데이터 = 상품 이미지·이름·가격(매번 바뀜). 자동화란 엔진은 그대로 두고 데이터만 바꿔 결과물을 반복 생산하는 것
- **자동화 5단계**: 1) 포토샵 액션 → 2) 배치/Image Processor → 3) PSD/AEP 템플릿 → 4) 스크립트 → 5) 생성형 AI로 스크립트 생성·수정
- 오늘 실습 이미지는 전부 **ComfyUI(생성형 AI)로 제작**됨
