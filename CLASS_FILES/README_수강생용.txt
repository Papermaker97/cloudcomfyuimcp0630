 신세계라이브쇼핑 · 방송 업무 AI 자동화 공통과정
 실습 파일 사용 안내  (수강생용)
============================================================

[ 준비 ]
1) 이 압축 파일(CLASS_FILES.zip)을 "바탕화면"에 풀어주세요.
   → 바탕화면에 CLASS_FILES 폴더가 생깁니다.
2) 폴더 이름과 파일 이름은 절대 바꾸지 마세요.
   (스크립트가 이름을 기준으로 파일을 찾습니다)

[ 폴더 구성 ]
 CLASS_FILES
  ├─ 01_INPUT/         상품 이미지 원본 (product_01.png ...)
  ├─ 02_PHOTOSHOP/     banner_template.psd  (배너 템플릿)
  ├─ 03_AFTER_EFFECTS/ broadcast_template.aep (방송 영상 템플릿)
  ├─ 04_SCRIPT/        자동화 스크립트 + config.json + 예시/워크시트
  ├─ 05_OUTPUT/        결과물이 저장되는 곳 (처음엔 비어 있음)
  └─ 99_BACKUP/        완성본 백업 (수업이 밀릴 때 참고용)

[ 실습 순서 ]
 실습 01 · 규격 변환 (Photoshop)
   Photoshop > 파일 > 스크립트 > 찾아보기 > 04_SCRIPT/규격변환.jsx
   → 01_INPUT의 상품 이미지가 3규격 JPG로 05_OUTPUT에 저장됩니다.

 실습 02 · 배너 자동 채우기 (Photoshop)
   ① 04_SCRIPT/config.json 을 메모장으로 열어 상품명·가격·이미지를 바꿉니다.
   ② Photoshop > 파일 > 스크립트 > 찾아보기 > 04_SCRIPT/배너채우기.jsx
   → banner_template.psd에 값이 채워진 배너가 05_OUTPUT에 저장됩니다.

 실습 03 · 방송 영상 자동 채우기 (After Effects)
   ① (최초 1회) After Effects > 편집 > 환경 설정 > 스크립팅 및 표현식
      > "스크립트가 파일에 쓰고 네트워크에 액세스하도록 허용" 체크
   ② After Effects > 파일 > 스크립트 > 스크립트 파일 실행 > 04_SCRIPT/영상채우기.jsx
   → 템플릿이 채워지고 OUTPUT 컴포지션이 렌더큐에 올라갑니다.
     하단 렌더링 대기열에서 "렌더링"을 누르면 영상이 05_OUTPUT에 저장됩니다.

[ config.json 편집 시 4가지 규칙 (오류의 90%) ]
   1) 값과 값 사이에는 쉼표(,)
   2) 맨 마지막 값 뒤에는 쉼표 없음
   3) 글자 값은 큰따옴표("")로 감싸기
   4) 파일 경로도 큰따옴표 안에 (예: "01_INPUT/product_01.png")

   당황하지 마세요. 오류창의 내용을 그대로 복사해서
   ChatGPT / Claude 에 붙여넣고 물어보는 것이 오늘 배우는 방법입니다.
   → 04_SCRIPT/프롬프트_예시.txt 의 [3]번 프롬프트를 사용하세요.
