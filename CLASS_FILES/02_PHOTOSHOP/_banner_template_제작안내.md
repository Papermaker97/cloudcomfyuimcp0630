# banner_template.psd 제작 안내 (강사용)

이 폴더에는 **`banner_template.psd`** 파일이 들어가야 합니다.
아래 규격을 지켜 만들면 `04_SCRIPT/배너채우기.jsx`가 그대로 동작합니다.
(스크립트는 **레이어 이름**을 기준으로 요소를 찾습니다 — 이름이 규격의 핵심)

## 캔버스
- 권장 크기: **1080 × 1080** (정사각) — 방송 배너 기본형
- 색상 모드: RGB / 8bit

## 레이어 구성 (이름은 영문 대문자 + 언더스코어, 한글 금지)

| 레이어 이름 | 종류 | 역할 | 스크립트가 하는 일 |
|---|---|---|---|
| `PRODUCT_IMAGE` | **스마트 오브젝트** | 상품 사진 | 내용물을 config의 이미지로 교체 |
| `PRODUCT_NAME` | **텍스트** | 상품명 | 글자를 config.productName으로 교체 |
| `PRICE` | **텍스트** | 가격 | config.price를 "25,000원"으로 교체 |
| `LOGO` | 고정 요소 | 더미 브랜드 로고 | 건드리지 않음 |
| `BACKGROUND` | 고정 요소 | 배경 | 건드리지 않음 |
| `DESCRIPTION` | (선택) 텍스트 | 보조 문구 | 사용 안 함(있어도 무방) |
| `CALL_TO_ACTION` | (선택) 텍스트 | "지금 구매" 등 | 사용 안 함(있어도 무방) |

## 만드는 순서 (요약)
1. 새 문서 1080×1080 생성.
2. `BACKGROUND` 색/이미지 배치 → 레이어 이름을 `BACKGROUND`로.
3. 상품 자리에 이미지 하나 배치 → 우클릭 **"고급 개체로 변환"(스마트 오브젝트)** → 이름을 `PRODUCT_IMAGE`로.
4. 텍스트 도구로 상품명/가격 입력 → 각각 이름을 `PRODUCT_NAME`, `PRICE`로.
5. 더미 로고 배치 → 이름 `LOGO` (⚠️ 실제 신세계 로고 사용 금지 — 사용 허가 없음).
6. **고정 요소 그룹 / 가변 요소 그룹**으로 묶어 레이어 패널에서 한눈에 구분되게 정리.
7. `.psd`로 저장 (파일명: `banner_template.psd`).

## 주의
- 유료 마켓 템플릿을 그대로 넣어 25~30명에게 zip 배포하면 **재배포 라이선스 위반** 소지.
  → 직접 제작하거나, 재배포 허용/직접 제작 소스만 사용.
- 텍스트 레이어는 실제 "텍스트 레이어"여야 함 (래스터화된 글자 이미지 X).
- 스마트 오브젝트가 아니면 이미지 교체가 안 됨 → 반드시 스마트 오브젝트로.
