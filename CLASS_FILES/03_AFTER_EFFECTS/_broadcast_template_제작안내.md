# broadcast_template.aep 제작 안내 (강사용)

이 폴더에는 **`broadcast_template.aep`** 파일이 들어가야 합니다.
아래 규격을 지켜 만들면 `04_SCRIPT/영상채우기.jsx`가 그대로 동작합니다.
스크립트는 **푸티지 이름 / 컴포지션 이름 / 레이어 이름**으로 요소를 찾습니다.

## 프로젝트 패널 구조 (교안 다이어그램 기준)
```
에셋   ├─ PRODUCT_IMAGE   (푸티지: 상품 이미지 소스)   ← 스크립트가 소스 교체
      └─ LOGO            (푸티지: 더미 로고, 고정)
텍스트  ├─ (MAIN 컴포지션 안의 텍스트 레이어로 관리)
컴포지션 ├─ MAIN           (1920×1080, 10초 내외 — 실제 디자인)
       └─ OUTPUT         (최종 출력용 — MAIN을 담은 컴포지션)
```

## 필수 이름 (정확히 일치 — 한글/공백/오타 금지)

| 이름 | 종류 | 스크립트가 하는 일 |
|---|---|---|
| `PRODUCT_IMAGE` | 푸티지(소스 파일) | 소스를 config의 상품 이미지로 교체 |
| `MAIN` | 컴포지션 | 이 안의 텍스트 레이어를 교체 |
| `PRODUCT_NAME` | MAIN 안의 **텍스트 레이어** | config.productName으로 교체 |
| `PRICE` | MAIN 안의 **텍스트 레이어** | config.price를 "25,000원"으로 교체 |
| `OUTPUT` | 컴포지션 | 렌더큐에 추가됨 |

## Essential Graphics 등록 4개 (교안 필수 항목)
MAIN 컴포지션을 열고 **필수 그래픽(Essential Graphics)** 패널에서 아래 4개를 등록:
1. **상품명** — `PRODUCT_NAME`의 소스 텍스트
2. **가격** — 슬라이더 제어(값)  ※ 이펙트 이름을 정확히 `가격`으로
3. **브랜드 컬러** — 색상(채우기) 컨트롤
4. **상품 이미지** — 미디어 교체 슬롯(`PRODUCT_IMAGE`)

## 표현식 2종 적용 (`04_SCRIPT/표현식_예시.txt` 코드 그대로)
1. **배경 박스 자동 리사이즈** — 사각형 셰이프의 `콘텐츠 > 사각형 경로 > 크기(Size)`에 적용
   - ⚠️ 셰이프 레이어 자체가 아니라 **사각형 경로의 Size**에 적용 (아니면 undefined 오류)
   - "위치(Position)" 짝꿍 표현식과 세트로
2. **가격 카운트업** — 가격 텍스트의 `소스 텍스트`에 적용
   - 슬라이더 이펙트 이름 `가격`이 표현식과 **글자 단위로 일치**해야 함

## 저장/호환 주의 (대여 노트북 버전 미확인)
- **낮은 버전 호환으로 저장** (파일 > 다른 이름으로 저장 > 하위 버전 사본).
- 신기능·무거운 이펙트(모션 블러 과다, 3D, 서드파티 플러그인) **사용 금지**.
- `toLocaleString` 등 JS 엔진 버전 종속 기능 회피 (예시 코드는 이미 회피됨).
- MAIN은 10초 내외 — 25~30명 동시 미리보기 대비.

## 검증 (배포 전)
- `영상채우기.jsx` 실행 → 오류 없이 텍스트/이미지 교체되고 OUTPUT이 렌더큐에 뜨는지.
- 일부러 레이어 이름을 틀리게 바꿔 실행 → 친절한 한국어 오류가 뜨는지.
