# LoRA 학습 가이드: 제품 LoRA 만들기 (Z-Image Turbo · fal)

Week 5 강의자료 · 예제: 러닝화 1켤레 (트리거 `oncld_shoe`)

---

## 1. LoRA가 하는 일

- 베이스 모델은 "운동화"는 그릴 수 있지만 **이 운동화**는 모릅니다. 프롬프트로 아무리 자세히 설명해도 로고, 밑창 모양, 배색이 매번 조금씩 달라집니다.
- LoRA는 베이스 모델 위에 덧붙이는 작은 추가 가중치 파일(`.safetensors`)입니다. 특정 대상이나 스타일을 모델에 "심어서", 트리거 단어 하나로 불러올 수 있게 합니다.
- ComfyUI에서는 MODEL 경로에만 걸립니다(`Load LoRA` 노드). 텍스트 인코더와 latent는 그대로이므로, LoRA를 켜고 끌 때 생기는 차이는 LoRA 때문입니다.

### 대상 LoRA와 편집 LoRA는 데이터가 다르다

| 종류 | 무엇을 배우나 | 데이터 | 예 |
|---|---|---|---|
| 대상(Subject) LoRA | 특정 인물·제품의 생김새 | 같은 대상의 사진 여러 장 + 캡션 | 이 운동화, 특정 자동차 |
| 스타일 LoRA | 색감·질감·화풍 | 같은 스타일의 서로 다른 이미지 | 브랜드 그레이딩, 필름 룩 |
| 편집(Edit) LoRA | "이렇게 바꿔라"라는 변환 | **전/후 쌍** 이미지 | Body Swap(BFS), 배경 제거, 재조명 |

오늘 실습은 **대상 LoRA**입니다.

## 2. 이미지 가이드

### 기본 원칙
> **대상은 항상 같고, 나머지는 전부 달라야 한다.**

모델은 "모든 사진에 공통으로 있는 것"을 트리거 단어에 붙여 학습합니다. 14장이 전부 흰 배경이면 흰 배경도 "이 운동화"의 일부로 학습됩니다.

### 권장 사양

| 항목 | 권장 | 비고 |
|---|---|---|
| 장수 | 15~30장 | 오늘 예제는 14장. 10장 이하는 각도가 부족해지기 쉬움 |
| 해상도 | 긴 변 1024px 이상 | 512px 이하는 로고·메쉬 디테일이 약해짐 |
| 형식 | JPG / PNG (RGB) | 투명 PNG는 흰 배경으로 합쳐서 저장 |
| 대상 크기 | 화면의 30~70% | 너무 작으면 디테일 학습이 안 되고, 꽉 차면 전체 형태를 못 배움 |
| 초점 | 대상에 정확히 | 흐린 컷은 빼는 게 낫다 |

### 다양하게 섞을 것

- **각도:** 양쪽 측면, 앞 45°, 뒤 45°, 정면, 정후면, 위, 밑창, 로우앵글
- **거리:** 전체 컷 + 디테일 클로즈업(로고, 밑창, 끈) 2~3장
- **배경·조명:** 스튜디오(흰색·회색), 실내 자연광, 야외 낮, 해질녘, 밤
- **사용 상황:** 한 켤레 나란히, 손에 든 컷, 신은 컷(발·다리만)

### 빼야 할 것

- 흐리거나 대상이 잘린 컷
- 다른 제품이 같이 크게 나온 컷
- 워터마크나 가격표·텍스트가 겹친 컷
- **투명 배경 체크무늬가 이미지에 박힌 컷.** 웹에서 PNG를 스크린샷하면 자주 생기며, 체크무늬까지 학습됩니다. 흰색으로 지우거나 빼세요.
- 거의 같은 컷의 반복(같은 각도·같은 배경 여러 장)

### 출처

직접 촬영한 사진이 가장 좋습니다. 공식몰·리테일러 사진은 연습·시연용으로만 쓰고, 결과물을 광고나 외부 공개용으로 쓰지 마세요.

## 3. 캡셔닝

### 규칙

1. **모든 캡션은 트리거 단어로 시작합니다.**
   `oncld_shoe running shoe, ...`
   - 트리거는 실제로 없는 단어로 만듭니다(`oncld_shoe`). `shoe`처럼 흔한 단어는 모델이 이미 아는 의미와 섞입니다.
   - 뒤에 붙인 `running shoe`는 이것이 무엇의 한 종류인지 알려주는 단어입니다.
2. **대상 자체의 특징은 쓰지 않습니다.** (색, 로고, 메쉬, 밑창 구멍 모양 등)
   - 쓰지 않은 특징이 트리거 단어에 붙습니다. "분홍 버건디"를 매번 쓰면 그 색은 프롬프트로 따로 불러야 하는 속성이 되어 트리거에서 빠집니다.
3. **바뀌는 것만 씁니다.** (각도, 한 짝/한 켤레, 배경, 조명, 손·발, 끈 상태)
   - 캡션에 쓴 것 = 나중에 프롬프트로 **바꿀 수 있는 것**입니다.
4. **사진에 실제로 있는 것만 씁니다.** 계획과 다르게 찍혔으면 캡션을 사진에 맞게 고칩니다.

### 예시 (오늘 데이터셋)

| 사진 | 캡션 |
|---|---|
| 한 켤레, 앞 45°, 연회색 스튜디오 | `oncld_shoe running shoe, a pair of shoes, front three-quarter view, on a light grey studio background, soft even light` |
| 한 짝, 앞코로 세움, 끈 늘어짐 | `oncld_shoe running shoe, a single shoe standing upright on its toe, loose laces hanging down, on a light grey studio background` |
| 신은 컷 | `oncld_shoe running shoe, worn on a foot stepping forward, black trousers, grey floor and light grey wall, side view` |
| 밑창 | `oncld_shoe running shoe, a pair of shoes, bottom view of the outsoles, on a white background` |

**나쁜 예:** `oncld_shoe pink and burgundy On running shoe with white sole and logo, on white background`
→ 색·브랜드·밑창을 다 적어서 트리거가 배울 게 줄어듭니다.

### 파일 구조

이미지와 캡션은 **같은 이름**으로 짝을 맞춰 하나의 zip에 넣습니다.

```
shoe_lora.zip
├── 01.jpg   01.txt
├── 02.jpg   02.txt
└── ...
```

각 `.txt` 파일에는 캡션 한 줄만 넣습니다.

## 4. fal에서 학습하기

> fal 화면 구성과 항목 이름, 가격은 자주 바뀝니다. 아래는 흐름이며, 실제 항목은 fal 화면에서 확인하세요.

1. **fal 로그인 → Models에서 Z-Image Turbo 트레이너 검색**
   - 반드시 **Z-Image Turbo용** 트레이너를 고릅니다. 학습한 베이스와 ComfyUI에서 쓰는 베이스가 같아야 LoRA가 제대로 동작합니다.
2. **데이터 업로드:** 위의 zip 파일을 올립니다.
3. **트리거 단어:** 입력 칸이 있으면 `oncld_shoe`를 넣습니다. 이미 캡션에 넣었으므로 캡션과 같은 단어를 씁니다.
4. **학습 모드:** content(대상) / style 선택이 있으면 **content**를 고릅니다.
5. **스텝 수:** 처음에는 기본값을 그대로 둡니다.
   - 비교 자료를 만들려면 **1000스텝과 2000스텝을 각각 학습**해 두는 것을 권합니다(6장 참고).
   - 비용은 스텝 수에 비례합니다(W4 자료 기준 약 $0.85 / 1000스텝. 현재 가격은 fal에서 확인).
6. **실행 → 완료 후 `.safetensors` 다운로드.**
   - 학습 중 샘플 이미지를 보여주는 옵션이 있으면 켜 두세요. 중간 결과가 그대로 수업 자료가 됩니다.

## 5. ComfyUI에서 쓰기

1. Comfy Cloud에 `.safetensors` 파일을 모델로 가져옵니다.
2. `W5_01_LoRA_Application_Comparison` 워크플로우를 엽니다.
   - 베이스: Z-Image Turbo (`z_image_turbo_int8_convrot`), 8스텝, seed 고정
   - `Load LoRA` 노드의 `lora_name`을 학습한 파일로 바꿉니다.
3. 프롬프트에 **트리거 단어를 꼭 넣습니다.**
   `oncld_shoe running shoe, front three-quarter view, on wet asphalt at night, neon reflections`
4. **한 번에 한 조건씩** 바꿔 실행합니다.
   - 강도(`strength`) 0 → 0.5 → 0.8 → 1.0
   - 라벨도 같이 바꿔서 결과 파일 이름으로 조건을 구분합니다. (예: `shoe_str0.80`)
   - 강도 0이 "LoRA 미적용" 조건입니다.
5. 같은 seed라도 결과가 완전히 똑같이 재현된다는 보장은 없습니다. 비교는 경향을 보는 것입니다.

## 6. 결과 판단하기

### 테스트 프롬프트 3종

| 목적 | 프롬프트 |
|---|---|
| 학습 데이터와 비슷한 조건 | `oncld_shoe running shoe, side view, on a white studio background` |
| 데이터에 없던 장소 | `oncld_shoe running shoe, worn on a foot, jogging on a beach at sunrise` |
| 데이터에 없던 연출 | `oncld_shoe running shoe, floating in mid-air, studio product shot, pastel background` |

### 상태별 증상

| 상태 | 증상 | 대응 |
|---|---|---|
| 덜 학습 | 비슷한 운동화지만 로고·배색·밑창이 틀림 | 스텝 늘리기, 디테일 클로즈업 추가 |
| 적정 | 형태·로고 유지 + 배경·연출이 프롬프트를 따름 | 이 지점을 사용 |
| 과학습 | 무엇을 요청해도 학습 사진과 같은 배경·각도로 나옴, 질감이 뭉개짐 | 스텝 줄이기, LoRA 강도 0.6~0.8로 낮추기 |
| 데이터 편향 | 특정 조건(밤, 야외)만 잘 안 됨 | 그 조건의 사진을 데이터에 추가 |

**오늘 데이터셋에서 예상되는 약점:** 14장 모두 밝은 스튜디오 배경이라 밤·야외 장면은 스튜디오 느낌으로 끌려갈 수 있습니다. 실제로 그런지 2번·3번 프롬프트로 확인해 보세요.
