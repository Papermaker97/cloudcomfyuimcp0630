# fal 업로드용 운동화 데이터셋 (14장, 캡션 포함)

- 이미지와 캡션 zip(`W5_shoe_lora_dataset_captioned.zip`)은 브랜드·리테일러 사진이 들어 있어서 저장소에 올리지 않았고, 채팅으로만 전달했습니다. 이 폴더에는 캡션 txt만 있습니다.
- zip 구성: `01.jpg` ~ `14.jpg` + 같은 이름의 `01.txt` ~ `14.txt`. 긴 변을 2048px 이하로 줄였고, 투명 배경과 체크무늬는 흰색으로 바꿨습니다(09, 12번은 원본에 체크무늬가 이미지로 박혀 있어서 흰색으로 채움).
- 트리거: `oncld_shoe running shoe`. 신발 자체의 특징(색, 로고, 밑창 모양)은 캡션에 적지 않았습니다.

## 데이터셋 상태

| 항목 | 상태 |
|---|---|
| 각도 | 측면, 앞 45°, 뒤 45°, 정후면, 위, 밑창, 클로즈업, 신은 컷 1장 → 양호 |
| 배경 | 14장 모두 흰색·연회색·베이지 스튜디오 → **편향 있음**. 야외나 어두운 배경을 생성하면 스튜디오 쪽으로 끌려갈 수 있음 |
| 해상도 | 02(512), 07(440), 09(480), 14(699×423) 등 1024px 미만이 많음 → 디테일이 약해질 수 있음 |
| 한 켤레 vs 한 짝 | 켤레 7장, 한 짝 6장, 신은 컷 1장 |
| 출처 | 공식·리테일러 사진. **수업 시연용으로만 쓰고, 결과물을 외부에 광고·상업용으로 쓰지 말 것** |

## fal 설정 (확인 필요)

이 환경에서는 fal 사이트에 접속할 수 없어서 현재 입력 항목 이름과 기본값을 확인하지 못했습니다.
- 모델: Z-Image Turbo 트레이너 (W5_01이 Z-Image Turbo 기반이라 그대로 비교 가능)
- 입력: 이 zip (이미지 + 같은 이름 txt 캡션). fal 트레이너가 txt 캡션을 읽는지, 트리거 단어를 따로 넣는 칸이 있는지 화면에서 확인할 것. 따로 넣는 칸이 있으면 `oncld_shoe`
- 학습 모드: 특정 사물이므로 content(대상) 쪽
- 스텝: fal 기본값부터. 1000스텝 결과와 2000스텝 결과를 둘 다 받아 두면 수업에서 덜 학습 / 적정 / 과학습 비교에 쓰기 좋음
- 결과 `.safetensors`는 Comfy Cloud에 모델로 가져온 뒤 W5_01의 LoRA 칸에 넣음
